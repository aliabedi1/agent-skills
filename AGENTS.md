# Repository Instructions

- At the end of every completed task that changes repository files, run the relevant validation, check `git status`, commit all task-related changes, and push the commit to the current remote branch.
- Never include unrelated user changes in the commit. If the worktree is mixed, stage only the files that belong to the task.
- If committing or pushing is not possible, clearly report the blocker and leave the task-related changes intact.
